# PrestaShop modul balikobotbranches
- Rozšíření modulu balíkobot o napojení na výdejní místa dopravců: GLS, PPL, DPD, Zásilkovna, Česká pošta apod.

# Postup nasazení
- je nutné mít nainstalován v prestashopu modul balíkobotu: "monster_balikobot" nebo "am_balikobot" verze alespoň 2.1.300
- modul "balikobotbranches" stačí pouze nainstalovat a napojení s moduly výdejních míst bude dokončen
